Install eaShot

This beta is signed with Developer ID and Apple-notarized for macOS 15 or later. It includes native Apple silicon and Intel code.

Prefer the Mac App Store? Version 1.0 is with Apple for review at US$4.99 as a one-time purchase. Local App Store pricing varies. This page remains the direct beta installation path.

Install

  1. Download eaShot-1.0.0-beta.2.dmg.
  2. Open the DMG and drag eaShot onto the Applications shortcut.
  3. Eject the disk image, then open eaShot normally from Applications. Do not bypass Gatekeeper if macOS reports a damaged app or unidentified developer.

Allow Screen Recording

Open the eaShot picker and choose Request Access. macOS controls this permission in System Settings → Privacy & Security → Screen & System Audio Recording. If macOS requests a relaunch, quit and reopen eaShot, then choose Refresh.

Your first capture

Choose Left, Right, Top, Bottom, or Full from the menu-bar picker. A successful choice becomes your next Quick Capture by default. Open Settings from the gear to record a global shortcut or turn off remembering and pin a preset. Shortcuts start unset so eaShot does not take over an existing macOS key combination.

Verify the download

Download the adjacent checksum, then run shasum -a 256 ~/Downloads/eaShot-1.0.0-beta.2.dmg. Its value must match the published checksum before you install.

Remove

Quit eaShot and move it from Applications to the Trash. Disable Launch at Login first if enabled. You can remove its Screen Recording permission in System Settings.
