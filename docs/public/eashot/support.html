Product support

Support

Found a problem or have an idea? Use the public support request. Check the report carefully and remove private window titles, documents, email addresses, and sensitive screenshots before submitting.

Open support requestMac App Store page

Capture access is not allowed

Open System Settings → Privacy & Security → Screen Recording, allow eaShot, and relaunch if requested. Then open the picker and choose Refresh.

The wrong display was captured

Move the pointer onto the intended display before invoking Quick Capture. eaShot deliberately uses the display under the pointer.

Protected video is blank

macOS and content providers can prevent protected media from appearing in screenshots. This is not something eaShot attempts to bypass.

A folder capture fails

Open eaShot Settings and choose the folder again. The folder may have moved, been removed, or had its permission revoked.

App Store refunds

Purchases and refunds are handled by Apple. Use reportaproblem.apple.com and mention the app name and purchase date.

Useful support report

Include the eaShot version/build, macOS version, Mac model/architecture, selected region and output mode, the exact visible error, and whether the problem reproduces after relaunch. Never send a sensitive screenshot unless you have deliberately redacted it. The support request is public and requires a GitHub account.
