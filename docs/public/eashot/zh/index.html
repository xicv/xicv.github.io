常见问题

支持哪些 macOS 版本?

macOS 15 或更高版本,支持 Apple 芯片和 Intel 芯片。eaShot 是通用二进制应用并已启用沙盒。

为什么 eaShot 需要屏幕录制权限?

macOS 要求所有读取屏幕像素的应用获取这一次性的权限。在应用请求时批准即可(系统设置 → 隐私与安全性 → 屏幕录制)。你随时可以撤销授权。

eaShot 会上传我的截图吗?

不会。捕捉只会进入剪贴板,以及你明确指定的文件夹。没有账户、没有分析、没有云服务。用于建议的历史记录只存储区域、比例、来源和时间——从不存储像素或应用名称。

它和 CleanShot X 或 Shottr 有什么不同?

它们是优秀的截屏套件,带编辑器、OCR 和录屏。eaShot 只做一件事:把重复的锚定区域变成一次按键,价格只是一杯咖啡的一半。很多人两者都用——日常重复交给 eaShot,需要标注时再用套件。

有免费试用吗?

Mac App Store 的付费应用不提供试用。但单次 US$4.99 买断的好处是:它永远是你的——没有需要记得取消的订阅。

可以自定义快捷键吗?

可以。快速捕捉和打开选择器都支持在 设置 → 快捷键 中录制自定义全局快捷键。默认不设置,eaShot 绝不会占用 macOS 已有的快捷键。
