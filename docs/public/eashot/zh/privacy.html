隐私

eaShot 是一款本地 macOS 工具。应用没有账户、分析、广告、云端上传或网络服务。

屏幕访问

macOS 的屏幕录制权限允许 eaShot 读取屏幕上的可见像素。eaShot 只在你触发捕捉后才请求截图,不会运行后台屏幕流。macOS 或内容提供方可能会阻止受保护内容被捕捉。

截图输出

仅剪贴板模式会把 PNG 数据放入系统剪贴板,不会创建任何属于 eaShot 的截图文件。文件夹模式只写入你明确选择的文件夹。该文件夹权限通过保存在这台 Mac 上的安全作用域书签来维持。

记住的区域与建议

记住的快速捕捉偏好只包含区域和比例。可选的建议历史还包含捕捉是由菜单、选择器还是快速操作触发,以及时间戳。它绝不包含截图像素、文件名、应用名称、窗口标题、剪贴板内容或按键记录。历史有上限,可以重置,建议也可以关闭。

诊断日志

本地 macOS 日志可能包含预设名称、输出像素尺寸、捕捉时长和错误描述。它们不会有意包含截图数据、文件名、应用名称或窗口标题。

共享与保留

应用不会向开发者传输个人数据。本地偏好和建议历史会一直保留,直到你重置它们或删除应用数据。你创建的文件和剪贴板内容由 macOS 以及你粘贴到的应用控制。

本网站

本静态网站由 GitHub Pages 托管。GitHub 可能会按照 GitHub 隐私声明处理标准请求信息,例如 IP 地址、浏览器信息、请求的 URL 和时间。eaShot 不添加任何网站分析、Cookie、表单或跟踪脚本。

你的控制权

你可以在 eaShot 设置中重置建议历史、更换或清除输出文件夹、删除你创建的文件,并在系统设置中撤销屏幕录制权限。删除 eaShot 的容器即会删除其本地偏好和历史。开发者没有可供取回或删除的服务器端应用数据。

联系与变更

隐私问题可以通过 eaShot 支持页面发送。未来版本如果加入支付、分析、网络、账户或在线服务,必须先发布修订后的政策,再启用相关行为。
