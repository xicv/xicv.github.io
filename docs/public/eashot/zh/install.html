eaShot 已上架 Mac App Store。单次购买,无订阅。通用二进制,支持 Apple 芯片与 Intel 芯片,需要 macOS 15 或更高版本。更新通过 App Store 自动推送。

安装

  1. 在 Mac 上打开 App Store,搜索 eaShot,或直接使用上面的链接。
  2. 点击价格购买,然后点击安装。应用会像其他 App Store 应用一样下载。
  3. 从"应用程序"中打开 eaShot。它常驻菜单栏——不会占用程序坞图标。

允许屏幕录制

首次启动时,eaShot 会显示一段简短说明和一个"继续"按钮。macOS 要求捕捉屏幕像素的应用获取这项权限。在 系统设置 → 隐私与安全性 → 屏幕录制 中允许 eaShot,如果 macOS 要求,重新启动一次。

你的第一次捕捉

从菜单栏选择器中选择 左侧、右侧、顶部、底部 或 全屏。成功的选择默认会成为你的下一个快速捕捉。打开齿轮图标进入设置,录制全局快捷键、选择剪贴板或文件夹输出,或关闭记住功能并固定一个预设。快捷键默认不设置,eaShot 不会占用 macOS 已有的组合键。

删除应用

退出 eaShot,然后从"应用程序"中删除。如已开启,请先关闭"登录时启动"。你随时可以在系统设置中撤销屏幕录制权限。macOS 可能在卸载后仍保留授权决定;如需全新重装,可执行 tccutil reset ScreenCapture com.xicao.eashot。
