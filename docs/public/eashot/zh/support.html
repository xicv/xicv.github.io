支持

遇到问题或有建议?请使用公开的支持请求。提交前请仔细检查内容,移除私密的窗口标题、文档、邮箱地址和敏感截图。

提交支持请求Mac App Store 页面

无法捕捉屏幕

打开 系统设置 → 隐私与安全性 → 屏幕录制,允许 eaShot,如系统要求请重新启动。然后打开选择器并选择刷新。

捕捉到了错误的显示器

触发快速捕捉前,把指针移到你想捕捉的显示器上。eaShot 特意使用指针所在的显示器。

受保护视频是空白

macOS 和内容提供方会阻止受保护内容出现在截图中。eaShot 不会尝试绕过这一限制。

文件夹捕捉失败

打开 eaShot 设置,重新选择文件夹。该文件夹可能已被移动、移除或撤销了权限。

App Store 退款

购买和退款由 Apple 处理。请访问 reportaproblem.apple.com,注明应用名称和购买日期。

高效的支持报告

请包含 eaShot 版本/构建号、macOS 版本、Mac 机型/架构、所选区域和输出模式、确切的错误提示,以及重启后问题是否复现。除非刻意做了脱敏处理,请不要发送敏感截图。支持请求是公开的,需要 GitHub 账户。
