Privacy

eaShot is a local macOS utility. The app has no account, analytics, advertising, cloud upload, or network service.

Screen access

macOS Screen Recording permission allows eaShot to read visible pixels. eaShot requests a screenshot only after you trigger a capture. It does not run a background display stream. macOS or a content provider may prevent protected content from being captured.

Screenshot output

Clipboard-only mode puts PNG data on the system pasteboard and creates no eaShot-owned screenshot file. Folder modes write only to a folder you explicitly choose. The folder permission is retained using a security-scoped bookmark stored on this Mac.

Remembered regions and suggestions

The remembered Quick Capture preference contains only a region and ratio. Optional suggestion history also contains whether the menu, chooser, or quick action initiated a capture and a timestamp. It never contains screenshot pixels, filenames, app names, window titles, clipboard contents, or keystrokes. History is capped, can be reset, and suggestions can be disabled.

Diagnostics

Local macOS logs may contain the preset name, output pixel dimensions, capture duration, and an error description. They do not intentionally contain screenshot data, filenames, app names, or window titles.

Sharing and retention

The app does not transmit personal data to the developer. Local preferences and suggestion history remain until you reset them or remove the app's data. Files you create and clipboard contents are controlled by macOS and the apps you paste into.

This website

This static site and its downloads are hosted by GitHub Pages. GitHub may process standard request information such as IP address, browser details, requested URL, and time under GitHub's privacy statement. eaShot adds no site analytics, cookies, forms, or tracking scripts.

Changes

A future version that adds updates, payments, analytics, or networking must publish a revised policy before that behavior is enabled.
